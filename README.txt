PC Matic HelpDesk GitHub Pages website

Upload the CONTENTS of this ZIP directly into the ROOT of your GitHub Pages repository.
Do not upload the ZIP file itself and do not place all files inside an extra enclosing folder.

Expected repository structure:
- index.html
- articles.html
- support.html
- style.css
- article_index.csv
- articles/ (contains all 100 individual article HTML pages)

GitHub Pages settings:
1. Open repository Settings, then Pages.
2. Choose Deploy from a branch.
3. Select the branch you publish from (usually main) and the /(root) folder.
4. Save and wait for deployment to finish.

All article links use the /articles/ directory. The getchatsupport.net destination is included only as the inner button on support.html.
PC Matic HelpDesk is an independent informational website and is not affiliated with PC Matic.
